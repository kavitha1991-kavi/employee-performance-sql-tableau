Employee Performance Analysis Project

## Project Overview
This project analyzes employee performance and HR metrics using SQL and Tableau. The objective is to extract meaningful insights from employee datasets to support better workforce management, performance evaluation, and strategic HR decisions.

The analysis focuses on key HR indicators such as employee performance ratings, department productivity, attrition patterns, and workforce distribution.

## Objectives
- Analyze employee performance metrics
- Identify high-performing departments and employees
- Examine workforce distribution across departments
- Detect potential attrition risks
- Visualize HR KPIs through an interactive dashboard

## Tools & Technologies
- SQL – Data querying and analysis
- Tableau – Data visualization and dashboard development
- Excel – Data preparation

## Dataset
The dataset includes the following fields:

- Employee ID
- Department
- Job Role
- Performance Rating
- Salary
- Years of Experience
- Attrition Status
- Training Hours
- Promotion Status

## Project Workflow

### 1. Data Preparation
- Cleaned and structured employee dataset
- Removed duplicates and handled missing values
- Standardized column formats

### 2. SQL Data Analysis
Used SQL queries to analyze HR metrics including:

- Average performance rating by department
- Employee distribution across job roles
- Attrition trends
- Salary distribution
- Top-performing employees

Example SQL concepts used:
- Joins
- Aggregations
- Group By
- Filtering

### 3. Tableau Dashboard Development
Created an interactive HR dashboard to visualize key insights including:

- Employee performance distribution
- Department-wise performance comparison
- Attrition analysis
- Salary vs performance trends
- Workforce composition

## Key Insights
- Certain departments demonstrate consistently higher performance ratings
- Employees with higher training hours tend to have stronger performance outcomes
- Attrition rates are higher among employees with lower performance scores
- Performance trends vary across departments and job roles
